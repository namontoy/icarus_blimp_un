permanent. They are published third-party work, so the citation is kept here and
the file is re-downloadable. If you have the PDFs locally they will sit in this
directory ignored; if you are reading this from a fresh clone, the directory will
be empty and the links below are how to refill it.

## One caveat about re-obtainability

Seven of the eight have a DOI or an arXiv id and can be refetched indefinitely.
**`Blimp Poster_ece.pdf` cannot** — a 2001 undergraduate research poster with no
DOI, no arXiv entry and no stable URL. The copy on this machine may be the only
one you will find. It is excluded from git along with the rest, so if it matters,
back it up somewhere that is not this disk.
